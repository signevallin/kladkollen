# Landningssidans skärmdumpar

Landningssidan (`public/landing.html`) visar dessa app-skärmdumpar i telefonramar.
Lägg PNG-filerna här med exakt dessa namn (stående, ca 9:19.5, t.ex. 1179×2556):

| Fil | Skärm | Plats på sidan |
|-----|-------|----------------|
| `wardrobe.png` | Garderoben (Wardrobe) | Hero, högst upp |
| `home.png` | Hemskärmen (Generate outfits) | Funktion 01 |
| `palette.png` | Färgpaletten (Palette) | Funktion 03 |
| `pregnancy.png` | Gravidläget (Pregnancy) | Funktion 04 |
| `trip.png` | Reseplanering (Plan the trip) | Funktion 05 |

Tills en fil finns visas en enkel "SKRUD"-platshållare i ramen (sidan ser inte
trasig ut). Väder-notisen (funktion 02) byggs i HTML med rätt Skrud-ikon och
behöver ingen fil. Gravidläget (funktion 04) använder en inbyggd mockup.
